# network/pkg/core — サーバー基盤
> 日本語版 — English: [README.md](README.md)

全ネットワークサービス共通の基盤パッケージ。

- **Config**: `packages/hoconconfig` の 3 つの HOCON レイヤーを型付きランタイム設定ツリーにマージする。各サービスパッケージは `init()` 時に自身の `reference.conf` を登録する。オペレーターのオーバーライドはスタートアップ時に検証され、不正な値はブートを失敗させる — 機能がサイレントに無効化されることはない。
- **Secrets**: URI スキームによる解決（現時点では `file://`; `vault://`、`awssm://` はシームとして用意済み）。
- **アウトバウンド URL バリデーション**: SSRF 耐性チェック（ループバック、リンクローカル、クラウドメタデータレンジをブロック; ローカル開発向けに明示的なループバック許可オプトイン対応）。データ由来のエンドポイント（DID ドキュメント、呼び出し元が提供するアップストリームエンドポイント）への送信リクエスト前に必ず呼び出すこと。

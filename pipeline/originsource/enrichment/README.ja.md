# enrichment — Origin Source バリアント、N = 1
> 日本語版 — English: [README.md](README.md)

1つのパイプライン準拠入力と外部ルックアップ（DB / API）をジョインし、新たな FirstDrop を発行する。

## 規約

- `derived_from` には上流 Pipeline ソース DID がちょうど**1つ**含まれる。外部ルックアップ対象は含まれない — パイプライン準拠の署名エンティティではないため。
- `source_root` は単一ソース VC の正規化されたワイヤーバイトにコミットする。
- イングレス側は FilterConvert と同等の検証義務を持つ（上流 VC を派生元にする前に検証・保存する）。
- 境界トランスレーションアダプタ（外部エコシステム VC → dplaax FirstDrop）はこのバリアントの特殊形である：外部 VC は境界で再署名され、オリジンコミットメントからは除外される。

## ステータス

この PoC フェーズではインターフェース + 規約のみ。参照実装はまだ存在しない。

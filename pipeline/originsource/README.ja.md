# originsource — FirstDrop 発行コンポーネント
> 日本語版 — English: [README.md](README.md)

Origin Source コンポーネント型。その**唯一の定義的性質**は、新たな FirstDrop VC を発行すること（`previousCredential` が空 — チェーンを切断する）。内部メカニクス — 入力カーディナリティ、プール・キャッシュ状態、外部ルックアップ、集約ロジック — はプロトコル非可視であり、実装が自由に選択できる。

## オリジンコミットメント

パイプライン準拠ソースから派生する FirstDrop はそれらへのコミットメントを持つ：

- `derived_from` — 上流 Pipeline ソース DID の集合（重複排除済み；実際のソース発行者との集合一致は L2 監査で検証される）
- `source_root` — ソース VC の正規化されたワイヤーバイト上の RFC 6962 マークルルート（`packages/merkle`）
- `source_root_canonical` — リーフに使用された正規化器の名称

外部（パイプライン非準拠）入力 — ファイル、API プル、DB ルックアップ、境界エコシステム VC（SCITT / GAIA-X / …）— は `derived_from` や `source_root` のリーフに**含まれない**。外部エコシステムへの暗号的リンクは別のアダプタレイヤーの関心事であり、別途メタデータで表現する。

## バリアント（参照実装の命名、入力カーディナリティ N 別）

| バリアント | N | 内部メカニクス | 本リポジトリでのステータス |
|---|---|---|---|
| `externalsource/` | 0 | ネットワーク外からのインジェスト（HTTP プッシュ / ファイル / ポーリング） | `apipush/` 参照実装あり |
| `enrichment/` | 1 | 1つのパイプライン準拠入力と外部ルックアップのジョイン | インターフェース + 規約のみ |
| `aggregate/` | ≥ 1 | パイプライン準拠入力のプール + ウィンドウ / 集約 | インターフェース + 規約のみ |

バリアントは規約であり、型コントラクトの区別ではない — プロトコルレベルでは Origin Source 型は厳密に1つ。
